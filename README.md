# BITS — Logbook Classification

BITS es una aplicación portable para Windows que prepara bitácoras aeronáuticas escaneadas para su indexación en AirVault. Lee los datos de cada página, comprueba matrícula, fecha, número de bitácora y firmas, identifica casos que requieren revisión y ordena los PDF por aeronave o mes.

Cada corrida genera reportes CSV y JSON, estadísticas, registros de operación y los PDF de entrega. Todo el procesamiento se ejecuta localmente en CPU y puede funcionar sin conexión.

El manual de operación y la descripción técnica se encuentran en [docs](docs/README.md).
